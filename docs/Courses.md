PROJECT UPDATE: ADD "COURSES" FEATURE TO EDUNEST PLATFORM

Objective:
Add a new major feature called "Courses" to the EduNest platform. Courses should become one of the core learning features of the platform alongside notes and quizzes.

Sidebar Changes:
1. Add a new sidebar menu item called "Courses".
2. Place it immediately after the "Main" section in the sidebar.
3. Use a suitable icon such as a graduation cap or book icon.
4. When clicked, it should open the Courses page.

Courses Page Layout:
Create a dedicated Courses page that displays programming courses in a clean card/grid layout. Each programming language should act as a course category.

Categories to include:
- C Programming
- Python
- Java
- C++

Each category should display a list of structured learning courses.

Course Lists:

C Programming:
- Getting Started with C
- C for Everyone: Programming Fundamentals

- Computational Thinking with Beginning C
- C Programming: Language Foundations
- C Programming: Advanced Concepts

- Advanced C++ Programming

Course Card Structure:
Each course card should contain:
- Course title
- Short description
- Progress bar
- "Start Learning" button
- "Continue Course" button if already started

Dashboard Integration:
Update the user dashboard to include a new section called "Course Progress".

This section should display:
- Recently started courses
- Current progress percentage
- Continue learning button
- Total courses enrolled

Learning Interface:
When a user clicks a course:
- Open a course learning page
- Display lessons/modules in a vertical list
- Track progress automatically
- Allow marking lessons as completed

Design Requirements:
- Maintain the existing EduNest UI style
- Use modern course cards
- Add progress indicators
- Ensure responsiveness for mobile and desktop

Goal:
Make Courses a major learning component of the EduNest platform so students can not only download notes but also follow structured programming learning paths.
